# Technical Dossier Reading Guide

Choose the shortest path that matches your goal.

## Employer or reviewer

1. Start with the repository [engineering overview](../../ENGINEERING_OVERVIEW.md).
2. Read the [full technical dossier](FULL_TECHNICAL_DOSSIER.md) for the control and architecture inventory.
3. Use the [verification audit report](VERIFICATION_AUDIT_REPORT.md) for limitations and evidence quality.

## Maintainer or coding agent

1. Run `python scripts/check-repo.py`.
2. Inspect `.github/workflows/` for the current control definitions.
3. Read the full dossier only after checking current source and Git history.

## Interpretation rule

The dossier is point-in-time documentation. Executable source and fresh verification output are authoritative.
